# afrotools/examples

> Real-world projects that validate the Afro.tools registry.

---

## What is this?

This repository contains working projects that demonstrate African API integrations
in real application contexts.

Each project uses specs from [afrotools/afrotools](https://github.com/afrotools/afrotools)
as its integration layer. A spec reaches `verified` status once it is used
in a working project here.

Integrations are generated by AI coding agents using the
**[Afro.tools plugin](https://github.com/afrotools/afrotools)** or the
**[MCP server](https://mcp.afro.tools)** — not written by hand.

Any MCP-compatible tool works: Claude Code, Cursor, VS Code Copilot, Windsurf, and others.

Projects can be in any language or framework — Next.js, Laravel, Python, mobile.
What matters is that the integration works end-to-end.
